Gork GPT Commands

Here are the special commands you can use:

  • /help - Show this help message
  • /clear - Clear the conversation
  • /remember [text] - Store information in memory
  • /recall - Recall stored information
  • /forget - Clear the memory
  • /joke - Tell a random joke
  • /quote - Get a random quote
  • /fact - Get a random fact
  • /define [word] - Define a word
  • /calculate [expression] - Calculate math expressions
  • /ca - Show the current CA value
